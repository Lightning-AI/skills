# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By taking part in this project (issues, pull requests, discussions) you agree to follow it.

## Reporting

Report unacceptable behavior privately to **sjoshi@lightning.ai**. Reports are handled
confidentially by the project maintainers.
